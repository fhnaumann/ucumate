# ucumate (Go)

Native Go port of ucumate. **Work in progress, not usable yet.**

```sh
go get github.com/fhnaumann/ucumate/go
```

- Parser is generated from the shared grammar in [`../ucumate-port-parity/grammar`](../ucumate-port-parity/grammar).
- UCUM data comes from [`../ucumate-port-parity/ucum-essence`](../ucumate-port-parity/ucum-essence).
- Must pass the parity checks in [`../ucumate-port-parity`](../ucumate-port-parity).
- Releases are tagged `go/vX.Y.Z`.
