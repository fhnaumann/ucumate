# ucumate (Java)

The reference implementation. Published to Maven Central as `io.github.fhnaumann:ucumate-*`.

```sh
mvn verify -Dgpg.skip
```

The grammar, UCUM essence files and functional test suites are not in this tree. They live in
[`../ucumate-port-parity`](../ucumate-port-parity) and Maven picks them up from there.
